# 皮卡丘记账

一款免费、无广告、以本地数据为主的 Android 个人记账应用。当前是功能原型，使用黄色电系配色和原创闪电图标，不包含官方角色图片。

## 产品目标

- 记一笔足够快：打开应用后能直接记录收入或支出。
- 收支一目了然：按月份查看收支、结余和分类构成。
- 数据由用户掌握：首版默认保存在设备本地，并支持导出备份。
- 免费且无广告：核心记账功能不依赖广告或订阅。
- 支持用户选择的登录方式，并为 GitHub 用户提供可选的加密云备份。
- 首版只开发和发布 Android 版本；iOS 暂缓。

## 首版范围（MVP）

- 新增、编辑和删除收入/支出记录
- 金额、日期、分类、备注
- 月度收支与结余概览
- 按分类查看支出汇总
- 月预算与预算进度
- 按月份、类型和分类筛选账单
- 本地数据导出与恢复方案
- GitHub 登录、指定私有仓库的加密备份，以及每周提醒和联网后重试
- 微信或 QQ 登录（需完成对应开放平台应用注册）

## 暂不纳入首版

- 银行卡或支付平台自动导入
- 广告、付费订阅和复杂理财功能

## 技术路线

- 使用 Flutter 与 Dart；当前只生成 Android 工程，保留以后扩展平台的空间。
- 首版使用 SQLite 将账单保存在本地，不需要注册账号或联网。
- GitHub 同步将是明确选择开启的功能，只向用户指定的仓库上传加密备份。
- GitHub 功能目前是单向快照备份，不会在多台设备之间合并记录。加密口令在本机安全存储中供后台任务使用；换机恢复时仍需用户记住该口令。
- Android 的 WorkManager 和本地通知受系统调度与权限控制，时间不保证精确。应用不会替用户开启 VPN；如果 GitHub 暂时无法访问，后台任务会按系统规则重试。
- JSON 备份不加密；恢复备份会替换本机现有账单和预算，请妥善保管备份文件。
- 目标是轻量、响应快、无广告；性能以真机发布构建的实际表现为准。

## 本地运行

需要安装 Flutter、Android SDK，并连接 Android 手机或启动模拟器。在项目目录运行：

```sh
flutter pub get
flutter run
```

Android 包名仍是开发占位值，正式发布前需要替换。
